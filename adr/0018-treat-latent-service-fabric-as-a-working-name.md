# ADR-0018: Treat Latent Service Fabric as a working name

- **Status:** Accepted
- **Date:** 2026-08-17

## Context

The acronym LSF is already widely associated with existing workload-management products.

## Decision

Use `latent-fabric`, `latentd`, and `latent` for repository and binary identifiers until naming review completes.

## Consequences

Public branding and package namespaces may change before a stable release; contract package names require an explicit migration plan.
