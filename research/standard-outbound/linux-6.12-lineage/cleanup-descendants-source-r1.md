# Constructor descendants and once-only final child drain

This is an uninstalled source continuation of the separately frozen lifecycle,
entry and IRQ relay. It adds no workflow, kernel build, successful copy_process,
worker-ready result, installer or production selection. The original backing,
192 KiB infrastructure, 256 records and 1 MiB bootstrap bounds are unchanged.
Actual updated task/descriptor/child geometry and whole-image fit remain open.

The five finite actual constructor sites are credentials, their composite LSM
blob, sighand including its RCU wrapper, signal and enabled delay accounting.
They use the existing original device owner, real task/request/root generations
and fixed physical-bank records. The complete actual TU sizeof/alignment is
checked before admission and zeroing; the initialized composite LSM size is
used directly. Each constructor is one-shot, with no address or record reuse,
separate ledger, caller-supplied budget or retrospective pointer adoption.
Credential security is a child of the actual newly born credential; the other
objects are actual task children. A failed exact origin retains the bank.

Private prepare_creds/copy_creds copies preserve the maintained full reference,
keyring, ucount, abort and error actions. The selected clone flags equal the
actual kernel_thread translation of CLONE_FS|CLONE_FILES|SIGCHLD, including
CLONE_VM and CLONE_UNTRACED with the exit signal separate. No new user namespace
or thread-keyring branch can be selected, while those original bodies remain.
security_prepare_creds still executes the original registered hooks and error
cleanup with the real GFP operand. Composite size zero remains size zero.
The selected complete LSM hook allocation graph is explicitly unqualified.

Private copy_sighand runs the real maintained slab constructor, including both
siglock and signalfd_wqh, before copying actions under the original current
sighand lock. Its wrapper includes the actual sighand and rcu_head in the
original admission. Original signalfd_cleanup and reference decrement run at

The original normal cache path and original constructor remain present.

Private copy_signal preserves every original timer, list, waitqueue, rlimit,
tty audit, autogroup, mutex and rwsem statement. Final signal cleanup preserves

private storage guard. Private delay initialization clears the inherited

Original global credential and signal destructors gain exact final-storage
guards; the registered hook dispatch, key/group/user/ucount/userns releases and
ordinary frees stay in order. The real credential RCU callback remains the

The same original record remains live through the callback and blocks its real

The actual __put_task_struct entry gains a birth-authenticated one-shot latch
before the original destructors. At the original final cache boundary the task
has usage zero and the real destructor chain has already run once. The cache
guard latches WAITING and retains the physical task record while credential or
sighand RCU children remain. Child final return signals existing kthreadd only
after releasing the pool lock. Kthreadd performs the one physical task-view
return outside the original creation lock and after checking the original
generations and absence of live children. It never increments usage, calls
free_task or __put_task_struct again, or follows a retired child pointer.
