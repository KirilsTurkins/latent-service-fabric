# Private linear packet source draft

This draft is not installed, compiled by the maintained object campaign, or
qualified as Linux packet execution. The selected complete factory consumer
remains NULL. No CLI, operator setting, caller certificate or assertion enables
this source. The current implementation prefix is still incomplete.

Ordinary Linux 6.12.113 copied TCP writes use page fragments even without
MSG_ZEROCOPY. The existing order-7, noncompound bootstrap allocation cannot
safely become arbitrary independently referenced SKB pages. This draft instead
ports the copied-data branch to actual charged linear SKB heads and the existing
`skb_add_data_nocache` copy/checksum/error helper. It does not pretend disabling
scatter/gather makes the original page allocator disappear, split the backing,
forge page metadata, or replace ordinary host interfaces.

The source authenticates 49 whole maintained files, including 45 unchanged prior
route-cache input identities, and 22 additional complete definition preimages.
The current derivation emits 83 files: 70 prior outputs are byte exact and five
shared files have explicit packet extensions. The two TCP entry points retain
an exact entire original definition in the unselected branch. Their selected
normal path keeps the original body; only an original protected socket birth
routes to the private copy. Existing audit SKB routing remains separate.

The private constructor reserves a complete header and aligned linear
head/shared-info from the original context before publication. It uses the
actual maintained initialization and real dataref/users, clone, expand and
last-dataref release behavior. A complete original head span is validated before
shared-info derivation. Known audit births go to the existing audit dispatcher;
unknown interior addresses poison and retain instead of reaching a normal heap.
No new ownership table, allocator fallback, public address binder or grant is
introduced. Full backing stays charged separately from returned logical views.

The candidate copied-TCP path requires the actual non-GSO size goal to equal
MSS and fit 2,048 payload bytes. This is a constructor restriction, not extra
memory or byte authority. Zero-copy, splice, fast-open, repair, ancillary data
and unsupported send flags refuse before their original allocating paths.
Sequence accounting, copy-fault handling, partial-prefix return, waits, pushes
and errors retain the maintained algorithm. The full linear head is already
charged by `tcp_skb_entail`; copying bytes does not add the original independent
page-fragment charge again. FIN/RST/ACK/probe and receive-collapse constructors
select the same actual socket parent before allocation. Private listen,
fast-open, repair and receive injection refuse before their original paths.
The actual `__pskb_copy_fclone` and `skb_copy_expand` tails retain the original
copy/header semantics after checked headroom/size and complete linear-source
validation. The constructor selects `SKB_FCLONE_UNAVAILABLE` and uses no normal
fclone slab; real users/dataref semantics are unchanged. This draft
does not yet provide the entire TCP/TIME_WAIT, RX or device path.

The TCP 96 KiB, DNS 64 KiB, four context regions, 256 original records, 524,288-byte
backing and 1 MiB bootstrap ceiling stay unchanged. Return still does not make an
arena offset reusable inside a live context generation. The finite allocation
plan and retirement guarantees need completion before installation.

The remaining coherent group is still under implementation:

- Close remaining SYN/TIME_WAIT/control and retransmit alternatives, including
  producers without an application socket lookup and fragmentation/segmentation.
- Admit a dedicated finite virtio split-ring RX/TX producer under node-owned
  prepaid infrastructure before device/NAPI/ring/page allocation. Later packet
  or socket lookup cannot retroactively establish the RX origin.
- Preserve real DMA/ring ownership and return; authenticate all device feature,
  segmentation, checksum, MTU and unsupported packet-shape boundaries.
- Close neighbour/ARP, DNS/UDP, deferred packet work and all cross-owner copies,
  retaining actual normal traffic, route policy and mandatory security/audit.
- Complete physical layout/capacity admission, trusted installation, sealed
  image/BTF final-free producer and finite real-node/operator/conformance proof.

Protected receive collapse also validates the same original socket/context for
every input and successor packet before queue/header inspection. A foreign or
normal packet cannot be charged retroactively merely because a protected socket
consumes it. The later temporary-list cleanup retains its original ordering.

The twelve focused source controls passed. A tiny freestanding reference also
executes seventeen new packet controls plus all nineteen prior Netport and
twenty-four prior audit-SKB controls. The original maintained retransmit copy
demonstrates the normal-heap escape before the corrected dispatcher passes.
The reference explicitly serializes SKB geometry, atomics, locks and final
dataref behavior; it is not actual Linux layout, concurrency, DMA or final-free
evidence. Its earlier setup and copied-local-socket fixture failures remain
retained separately. The copied socket fields were correctly insufficient:
the corrected positive initializes the actual reserved original object.
No kernel/native/guest build or packet exchange has been run for this draft.

## Device initialization must precede its allocations

The existing one-MiB `StreamKernelBacking` reservation is a source API, not an
executed protected bootstrap. Ordinary virtio probe/virtqueue/NAPI allocations
precede the current factory open. A later node context, packet lookup or socket
label cannot make them prepaid. The candidate dedicated device must therefore
defer its allocating initialization until the original backing owner exists,
then allocate finite rings and buffers inside the existing infrastructure
reserve. Normal host traffic must retain its original path. The real driver
probe/bus lifetime, DMA mapping, dispatch and cleanup still need implementation;
using the unused tail or another owner slot alone would not close this gap.
