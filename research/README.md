# Research tracks

Research code must not become a required production dependency. Each track needs an explicit semantic model, portability statement, security analysis, benchmark, and promotion ADR.

These tracks remain exploratory after the [Phase 1 completion](../docs/phase-1-completion.md)
and [performance extension](../docs/phase-1-extension-completion.md). None is a
delivered standalone capability or a dependency of the Phase 1 gate. The next
feature phase is [packaging and supply chain](../docs/roadmap.md); research
promotion follows its own evidence and architecture review.
