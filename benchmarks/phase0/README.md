# Phase 0 baseline evidence

`raw-results.json` and `BASELINE.md` are generated by `tools/run_phase0_baselines.sh` from the same retained-process run. They are checked-in observational evidence, not an SLO or universal performance claim.

Regenerate a CI-sized comparison with:

```bash
tools/run_phase0_baselines.sh smoke target/phase0-baseline/smoke
```

Run the heavier local profile with:

```bash
tools/run_phase0_baselines.sh full target/phase0-baseline/full
```

Do not overwrite the reference files with results from a materially different CPU, memory size, OS/kernel, Rust/Wasmtime toolchain, target, build profile, fixture digest, pool topology, budget, or sample configuration without explicitly documenting the new environment and reason.
