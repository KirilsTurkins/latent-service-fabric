# Fixed-source Go HTTP lifecycle replay

This optional manual programme authenticates native products and the five normal
packages from source `3050cd9d33d74eed5d746f13fbb0e9125376a3b3`, run
39298177972/job118216070006. It retains the original normal qualification,
source inventories, package markers and raw node receipt unchanged. A fresh
normal 27-case signed run precedes one new application component and the
original 33 plus nine additional HTTP cases on that component.

Select both `fast_dependency_replay=true` and `fast_http_replay=true` on this
branch's existing Go workflow. The full native job and private/generator replay
are skipped; the normal workflow and dependency replay retain their previous
commands and default selection. No Cargo products are compiled by this lane.

The five native products, SDK/runtime production preimages, compiler tools and
recipe are authenticated against the fixed original receipt before use and
rechecked after execution. The new application is ordinary source under the
existing v4 profile. Its runtime-selection receipt necessarily has a new source,
component and WIT identity: the real producer/consumer validates those bindings,
profile and materials rather than comparing that application-bound digest with
the old greeting. Seven immutable compiler/SDK material identities still match
exactly. Original and selected source identities remain distinct.

The three fresh nodes must retire normally. Unknown outcomes, wrong revisions,
extra peer contacts, forwarded credentials, excess consumption or an unreaped
owner fail. This programme supplies a finite historical-compiler/current-fixture
observation; it does not requalify all current native or SDK sources, the two
published clients, all Go runtime semantics or whole-ticket completion.

For the root-return and root-panic cases, the client timeout is disabled and no
user cancellation or child join runs. The accepted body remains pending until
the activation owner retires it; the original host/root deadline and physical
owner fences remain. A guest timer or explicit application cleanup cannot supply
the retirement result.
