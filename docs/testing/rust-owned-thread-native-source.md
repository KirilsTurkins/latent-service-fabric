# Rust40 original-component native source checkpoint

This draft adds a distinct `rust-context40-sync-cooperative-v1` host profile.
The ordinary Rust builder remains closed. Signed execution of the captured
default ThreadPool application and runtime qualification are still pending.

The current compiled host catalogue borrows 177,210 original body bytes and
fixes all 1,222 function/data records and 5,312 actual relocation referents. Its
origin is the independently verified compiler observation at
`a9809cab6aa3021b29014bd8b80dd15922c93265`, run 41109207452, artifact
13003202462. That run compiled the original application but refused the stale
catalogue before component encoding or guest execution. Earlier observations,
including `28059f3` and the `ec11` failure, remain distinct historical events.
Guest JSON, names, producer strings and supplied rlibs never select or replace

Before any allocating component reader, the verifier compares raw framing
against the immutable normal encoder envelope. It then recomputes the complete
main core, including checked private dispatch, original Arc/destructor bodies,
the disjoint Root/System stacks and canonical result/panic guards. Every other
component section is exact, including the nested public WIT wrapper, canonical
primitive arguments and native-admission binding. This finite profile supports
only the retained greeting/result<string,string> WIT/import/encoder shape;
other shapes refuse.

The selected thread metadata adapter retains the complete original 1420-byte
WIT payload and changes only its public function's async effect. The complete
parsed graph differs only at `/interfaces/4/functions/greet/kind`. Actual pinned
normal encoding preserves the synchronous Core ABI and changes exactly three
public type bytes in the final component. This permits ordinary suspension
under Wasmtime's existing async-task rules; it changes no host sync-task rule.

The Rust profile has its own fingerprint, immutable prepared-cache proof and
48 MiB preparation allowance admitted before recomputation. It retains the
original Store/native owners and runtime limits and accepts only cooperative
manifests. It cannot replay a C144 or older Rust40 proof.
