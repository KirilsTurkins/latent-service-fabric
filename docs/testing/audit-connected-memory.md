# Original connected audit memory ownership

The journal and provider broker share one original node metadata bank. Fixed
Store, queue and shared-owner backing is admitted before allocation. Critical
Pending/Finish records, acknowledgement tickets and returned read-only views keep
their original prepaid payload graph alive through worker and final-clone
retirement. Activation memory owners retain physical storage without retaining
ordinary execution authority. Journal query pages and encoded replies carry the
same paid backing through the final returned response.

do not execute a signed guest, replace the immutable 193-control host tuple or
qualify opaque transport caches, private allocator/OS stack caches, every
instantaneous serde allocation peak, or complete runtime/whole-cost closure.
