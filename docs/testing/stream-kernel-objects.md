# Maintained kernel object check

The finite hosted Linux campaign authenticates the complete official 6.12.113
archive, all 71 independently corroborated source pins and two additional
Kbuild files from that same archive. It derives the actual maintained private
constructor and composite-security-blob source before invoking normal Kbuild.

The original x86-64 defconfig resolves first. The only allowed configuration
change then enables the private candidate symbol. INET, SECURITY,
SECURITY_NETWORK and SELinux must remain enabled, and every other resolved
symbol must stay equal, including memory-control configuration. The generated
autoconf header and private symbols in each output prevent a CONFIG-off compile
from being reported as validation.

Six targets typecheck the real socket, VFS inode, protocol, IPv4, security and
factory code with upstream headers and compiler flags. The campaign records the
actual compiler, configuration bytes, object identities, selected symbol names,
original-source derivation and bounded command logs. Failure evidence retains
the original stage and diagnostics. No local kernel build is performed.

The objects remain unlinked. There is no kernel image, boot, running BTF,
installed factory, active SELinux/Netlabel allocation closure, physical-free
qualification or production enablement. The complete consumer remains NULL.
This campaign alone completes no whole milestone ticket.
