# Current Linux stream kernel ownership

The real-provider reference distinguishes a file descriptor's destruction from
physical kernel retirement. It keeps the original activation, provider pool,
96 KiB socket reservation, endpoint grant, transfer limits and root deadline.
A held owned peer first applies actual send backpressure. The same socket is
then closed while that passive peer remains open, and observed again after the
peer drops. The observer binds the exact original loopback four-tuple/inode
privately; only fixed TCP state labels, finite numeric memory counters, original
lease counts and the observer-tool digest are retained. No address, port,
inode, payload, credential, raw ss output or /proc listing is published.

An ss row can demonstrate remaining kernel work. Neither a missing row, inode,
FD, accepted cancellation, fixed delay nor a zero logical counter proves the
kernel object has been freed. The observer always returns retirementProven=false,
including absent rows. The reference qualifies one named counterexample only;
its complete 26-case inventory retains all prior 25 controls, but those other
cases are not credited as executed by this focused lane. Every full-kernel,
full-TLS and production flag remains false.

The current source validates only the configured send/receive buffer sum, then
releases the socket reservation after the last Rust transport/FD owner drops.
That does not establish a hard all-time bound for skb/forward/option/backlog,
protocol structures or orphan/TIME_WAIT/RCU tails. Kernel version and observed
plateaus alone cannot qualify a supported production profile.

A supported kernel profile must authenticate the actual kernel/image and relevant
allocator/network configuration; establish a finite complete allocation bound
within the unchanged reservation before socket creation; and supply a sealed,
non-reusable retirement fact covering the original full socket and any derived
close-tail owners. Original activation/provider/currentness identity must survive
that transfer. The existing bounded maintenance/quarantine owner must retain the
original native and pool leases until that fact is established. Unknown profile,
unknown ownership, unsupported retirement observation or incomplete accounting
must refuse admission before contact or retain failed/quarantined ownership;
it must never turn a snapshot or timeout into a refund certificate.

The real Linux witness is the next implementation discriminator. Production
profile selection/retirement repair follows its actual result. This source-only
preparation neither enables an unqualified provider nor completes #738/#739/#740.
ACCOUNTING_QUALIFIED remains false; historical 0.23.45 observations are unchanged.

The finite ss vocabulary is checked against the [primary iproute2 format source](https://github.com/iproute2/iproute2/blob/v6.17.0/misc/ss.c). The actual installed tool digest is retained independently; that format reference is not an authenticated source binding for the runner kernel or tool binary.
