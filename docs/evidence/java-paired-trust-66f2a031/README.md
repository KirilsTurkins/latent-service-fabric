passed paired signing/admission subcampaign and its recorded individual
observations; it does not qualify the complete HTTP/context/cancellation/canary

The [paired trust receipt](paired-trust/paired-trust.json) records two independently

authoritative Rust canonical bytes/digests. All nine verifier negatives pass,
including revocation of the builder identity itself as well as its signing key.

actual admission grants expire after their two-second TTL and reject their
original reuse without entering either fenced action. The original raw-order
policy mistake remains rejected with its concrete mismatched digest.

The [standalone](standalone/workflow.json) and [HTTP](http/workflow.json) receipts
record successful publication/deployment, direct versus composed HTTP 200, the
real selected preparation profiles and eight generated-client checks. The fresh
domain's status method actually calls its declared monotonic provider. Its
[authorized context observation](http/context.json) shows the real adapter
Service child with a Binding/GrantDenied diagnostic when that child principal's
clock grant is denied. The child terminates with a guest trap; the adapter
returns HTTP 500. The scoped provider observation has `diagnosticIsTerminal=false`
and is not relabeled as a terminal diagnostic.

The later aggregate failure came from calling an accepted 20,565-byte metadata
input "oversized" despite the supported CLI's 32 KiB bound. That
[successful original invocation](http/controls/java-context-denied-oversized-context.json)
is retained. The maintained qualifier now uses an input above the bound and
checks the early CLI rejection in a separate attempt, as described in the
[published context guide](https://github.com/KirilsTurkins/latent-service-fabric/blob/a573957d4067e4db960cdb08681150762e3eb5a7/docs/component-development/java-http-context.md).

All trust is disposable short-lived demo trust; these receipts create no
authority and contain no private signing keys or production approval. Use the

remains unchanged; no result from this campaign is inserted into its receipts.
